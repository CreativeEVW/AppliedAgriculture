# 生物材料合成室 (Biomaterial Synthesis Chamber)

<BlockImage id="biomaterial_synthesis_chamber" scale="8" />

接入 ME 网络后，从生物模板中合成材料并将产物存入网络。
模板物品仅用于指定产物类型，不会被消耗。

## 消耗（每轮）

- 能量：200 AE（取自网络）

## 输入（中心槽，不消耗）

| 输入类型 | 产出 |
|----------|------|
| 鸡刷怪蛋 | 蛋 ×1 |
| 羊刷怪蛋 | 白色羊毛 ×1 |
| 牛刷怪蛋 | 奶蛋白 ×1 |
| 哞菇刷怪蛋 | 奶蛋白 ×1 + 真菌混合物 ×1 |
| 怪物磁盘（ME刷怪笼联动，可选） | 磁盘内所有成型实体同时产出 |
| 树苗 | 对应原木 ×5 + 树苗 ×1（橡树苗额外产苹果 ×1） |
| 蘑菇（棕色/红色蘑菇、绯红菌、诡异菌） | 同种蘑菇 ×3 |
| 凋零刷怪蛋（工业先锋联动，可选） | 以太气体 1b（随 IF 流体镭射钻配方同步） |
| 其他无专属产物的生物（工业先锋联动，可选） | 粉红色史莱姆 + 肉汤（按最大生命值，20 点生命 = 各 1b） |

## 升级卡（8 槽）

| 卡 | 最大数量 | 效果 |
|----|----------|------|
| 增产合成卡 | 6 | 每张使产出 ×3（满配 ×729） |
| 加速卡 | 2 | 周期 10s → 约 3.2s → 1s |

## 联动

- 安装 ME刷怪笼 后可放入怪物磁盘，磁盘内所有成型实体同时产出。
- 安装 工业先锋 后：树苗额外产出 1b 胶乳；实体流体产出跟随 IF 流体镭射钻配方（如凋零 → 以太气体）。
