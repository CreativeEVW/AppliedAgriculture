# 真菌混合物 (Fungus Mixture)

<ItemImage id="fungus_mixture" scale="8" />

由生物材料合成室（放入哞菇刷怪蛋）产出，也可用任意两个蘑菇合成。

- 可直接食用：回复 6 饱食度 + 7.2 饱和度，效果与蘑菇煲相同。
- 可代替蘑菇煲参与合成。
