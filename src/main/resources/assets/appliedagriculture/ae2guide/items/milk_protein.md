# 奶蛋白 (Milk Protein)

<ItemImage id="milk_protein" scale="8" />

由生物材料合成室（放入牛/哞菇刷怪蛋）产出，每轮 1 个（增产合成卡可乘倍）。

- 可直接食用：回复 3 饱食度 + 3 饱和度，并清除身上所有效果（与喝牛奶相同）。
- 可代替奶桶参与合成。
