# AppliedAgriculture

An **Applied Energistics 2 (AE2)** addon mod for **Minecraft 1.21.1** on **NeoForge**.

## About

AppliedAgriculture (应用能源：农牧业) brings agriculture and livestock automation to your ME network.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.230+
- Applied Energistics 2 19.2+
